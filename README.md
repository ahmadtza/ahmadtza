## Featured Project

### Bearing Fault MLOps

An end-to-end MLOps pipeline for **bearing condition diagnosis from three-channel vibration signals**.

The project covers:

- Leakage-aware validation grouped by independent physical run
- Frequency-domain feature engineering
- A fixed production feature contract
- scikit-learn model pipelines
- MLflow Model Registry and Champion-model management
- PostgreSQL metadata and MinIO artifact storage
- FastAPI model serving
- Nginx HTTPS and Basic Authentication
- Prometheus and Grafana monitoring
- Docker Compose deployment
- GitHub Actions CI and integration testing

**Repository:** [bearing-fault-mlops](https://github.com/ahmadtza/bearing-fault-mlops)
